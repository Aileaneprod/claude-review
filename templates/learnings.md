# Learnings for this repository

Lessons the AI reviewer should carry into every review of THIS repo. Copy this
file to `.claude-review/learnings.md` at your repo root and edit it.

Use it for conventions that are true here and nowhere else — what your ADRs are
for, which directories are generated, a naming rule a reviewer keeps getting
wrong. Lessons that would apply to any repository belong in claude-review's own
`prompts/learnings.md` instead.

Every line is read on every review, so it costs quota and competes with the diff
for attention. Keep it short and delete what stops earning its place.

Format: one `##` heading per lesson, an imperative rule, then the evidence that
earned it. Everything above the first `##` is ignored by the prompt builder, so
this preamble costs nothing.
