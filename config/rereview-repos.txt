# Repositories the scheduled catch-up sweeps.
#
# Read by scripts/rereview-all.sh, which runs scripts/rereview-open-prs.sh
# against each one. See .github/workflows/catch-up.yml for the schedule and
# docs/SETUP.md for the token it needs.
#
# Format — one repository per line, `#` comments and blank lines ignored:
#
#     OWNER/REPO [path to that repository's wrapper workflow]
#
# The second field is optional; without it the wrapper is assumed to live at
# .github/workflows/ai-review.yml, which is where install-wrapper.sh puts it.
#
# Order is priority order. The pass spends a shared budget from the top down,
# and names in the job summary whatever it did not reach.
#
# A repository belongs here once it is actually wired up: the catch-up reads
# its wrapper first and fails the run if there is none, because a name in this
# file that cannot be checked is a stale roster, and a stale roster reports
# reassuring zeros. Removing a repository from the system means removing it
# here too.
