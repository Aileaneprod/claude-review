# Invoicing scenarios

Every company, person and identifier in these scenarios is invented. No real
customer data may enter this directory.

Contact addresses use the `example.test` domain, which is reserved for testing
(RFC 6761) and can never be delivered to anyone.

Legal identifiers (SIREN, SIRET, VAT) must come from `IDENTIFIERS.md`, the list
of values checked one by one against the public registry and confirmed to be
unallocated. Do not generate new ones.
